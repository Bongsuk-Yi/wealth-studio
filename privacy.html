개인정보처리방침

이 사이트는 회원가입이 없고, 이용자가 입력한 자산·수입·지출 정보를 서버로 수집·전송하지 않습니다.

브라우저 저장

입력값과 시뮬레이션 결과는 이용자의 브라우저 로컬 저장소(localStorage)에만 저장되며, 브라우저 데이터를 지우면 함께 삭제됩니다.

외부 서비스

사이트는 GitHub Pages에서 제공되며, 글꼴을 Google Fonts에서 불러옵니다. 이 과정에서 해당 서비스가 접속 기록(IP 주소 등)을 처리할 수 있습니다.

문의

개인정보 관련 문의는 사이트 운영자의 GitHub 저장소 Issues로 남겨 주세요.
